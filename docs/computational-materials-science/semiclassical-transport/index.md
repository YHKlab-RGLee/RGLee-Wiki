# Semiclassical transport

전자 수송의 여러 regime을 구분하는 데서 출발하여 Boltzmann transport equation (BTE)의 정식화와 필요한 입력 파라미터, first-principles carrier mobility 계산으로 이어지는 문서들을 안내한다.

Electronic transport regimes는 두 수송 접근을 함께 살펴보는 입문 문서이다. NEGF 정식화와 계산 방법, 산란 모형은 [Quantum transport](../quantum-transport/index.md)에서 찾아볼 수 있다.
