# Electronic structure

전자구조를 계산하는 대표적인 이론적 방법과, 계산한 전자 상태를 실공간에서 분석하는 방법을 정리한 문서들을 연결한다.

관련 기저 구성·축소 방법은 [Wannier functions](../../computational-science/model-reduction/wannierization.md)에서 다룬다.
