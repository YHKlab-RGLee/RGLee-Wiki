# Molecular simulation

Molecular simulation은 계산 모형으로 원자계의 구조, 열역학량과 동역학량을 탐구하는 방법을 다룬다. 현재는 classical molecular dynamics와 ab initio molecular dynamics의 기본 원리, ensemble 선택, 수치 안정성 및 평형·표본화 판정을 설명한다.
