Solid-state physics 영역에서는 현재 실공간 electronic structure 분석, Green's function을 이용한 quasiparticle과 개방 양자계의 quantum transport, 반도체·절연체의 point defect 열역학과 비방사 운반자 포획을 다룬다.

### 2. Many-body perturbation theory
