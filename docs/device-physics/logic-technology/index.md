# Logic technology

Logic technology는 CMOS의 소자–회로 연결에서 반복 배치 가능한 논리 셀의 기하 구조와 회로 성능으로 이어지는 계층을 다룬다. Standard-cell architecture와 process–device–cell–block 사이의 design–technology co-optimization (DTCO)을 연결하여 설명한다.
