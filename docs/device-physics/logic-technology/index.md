# Logic technology

Logic technology에서는 CMOS transistor로 논리 회로를 구성하는 원리부터, 반복적으로 배치할 수 있는 standard cell의 물리적 구조와 회로 성능을 다룬다. 이후 공정·소자·cell·block의 설계 조건을 함께 최적화하는 design–technology co-optimization (DTCO) 방법으로 논의를 확장한다.
