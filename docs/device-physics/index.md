# Device physics

Device physics 영역은 MOSFET, memory device, logic technology, semiconductor process 및 device reliability로 구성된다. MOSFET 문서에서는 기본 동작과 누설 전류, short-channel effects 및 구조 발전을 다룬다. Memory device 문서는 시스템 계층에서 셀과 주변회로에 이르는 메모리 구조를 설명하며, logic technology 문서는 CMOS 회로에서 standard cell과 DTCO까지의 구현 단계를 연결한다. Semiconductor process 문서는 웨이퍼 준비부터 소자 형성, 배선, 패키징까지의 제조 공정을 다룬다. Device reliability 문서에서는 소자와 배선의 열화 메커니즘, 수명 시험 및 통계적 예측 방법을 설명한다.
