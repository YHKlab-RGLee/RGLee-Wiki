# DeepONet

Deep operator network (DeepONet)는 **입력 함수의 표본값을 처리하는 branch network와 출력 좌표를 처리하는 trunk network를 결합하여 함수 사이의 대응을 학습하는 모형**이다. 특정 입력 함수 하나의 출력 곡선만 근사하는 데 그치지 않고, 서로 다른 입력 함수에 공통의 매개변수를 적용하여 출력 함수가 어떻게 달라지는지 학습한다. 최종 예측값은 branch와 trunk가 출력한 두 벡터의 내적으로 구한다. 다만 입력 함수의 표본값을 branch의 잠재 벡터로 바꾸는 과정은 비선형일 수 있다.[1,2]

이 문서는 연속인 스칼라 입력 함수를 고정된 sensor 위치에서 표본화하고, 각 출력 좌표에서 스칼라 값을 예측하는 기본 DeepONet을 다룬다. 입력장은 $a$, 출력장은 $u$로 쓰며, 함수 사이의 대응이라는 공통 배경은 [Fourier neural operator](fourier-neural-operator.md)와 연결된다. 여기서는 Fourier 층 대신 입력에 따른 계수와 좌표에 따른 함수를 분리하는 표현을 설명한다. Physics-informed 확장도 이 표현에서 직접 도출하므로 별도의 선행 문서를 요구하지 않는다.

## 1. 연산자 학습의 대상

DeepONet의 학습 대상은 함수 공간 사이의 연산자 $\mathcal G$이다. 입력 영역을 $D$, 출력 영역을 $\Omega$, 각각의 함수 공간을 $\mathcal A$, $\mathcal U$라 하자. 입력 함수 $a$를 정하면 정답 출력 함수 $u$가 정해진다.[1,2]

$$
\mathcal G:\mathcal A\to\mathcal U,
\qquad a\mapsto u=\mathcal G[a].
$$

좌표 $x\in D$에서의 $a(x)$는 입력 함수의 한 값이고, $y\in\Omega$에서의 $u(y)$는 출력 함수의 한 값이다. 두 영역은 서로 같을 필요가 없으며, 예를 들어 입력은 공간상의 계수이고 출력은 시공간상의 해일 수 있다. 실제 network에는 입력 함수 전체를 연속적인 형태로 전달하는 대신 유한한 sensor 값으로 만든 배열을 넣는다. 따라서 학습하려는 수학적 연산자는 함수 사이의 대응이지만, network가 실제로 받는 입력 정보는 유한차원 배열이라는 점을 구분해야 한다.[1,2]

### (1) 함수 근사와 연산자 근사

고정된 입력 $a_0$에 대한 하나의 해만 맞춘다면 좌표를 받아 값을 출력하는 $f_\theta$를 학습할 수 있다. $\theta$는 학습 매개변수 전체이다.[2,3]

$$
f_\theta(y)\approx\mathcal G[a_0](y).
$$

연산자 학습에서는 같은 $\theta$로 여러 입력 $a$를 처리한다. 예측값을 $u_\theta[a](y)$라고 쓰면 목표는 다음과 같다.[1,2]

$$
u_\theta[a](y)=\mathcal G_\theta[a](y)
\approx\mathcal G[a](y),\qquad a\in\mathcal A.
$$

이미 주어진 입력 함수에 대해 새로운 좌표 $y$에서 평가하는 것은 같은 출력장의 다른 위치에서 값을 예측하는 일이다. 반면 새로운 입력 함수 $a$를 주면 이전에 학습하지 않은 입력에 대응하는 출력 함수 자체를 예측해야 한다. 따라서 출력 좌표를 바꾸어 얻은 정확도만으로 새로운 입력 함수에 대한 일반화 성능을 판단할 수는 없다. 특히 같은 정답장의 일부 좌표를 학습하고 나머지를 시험하는 실험은 새로운 입력 함수에 대한 시험과 다르다.[1,2]

### (2) 적분 연산자의 예

가장 간단한 예로 무차원 구간 $[0,1]$에서 연속인 입력 $a$에 대해 다음 초기값 문제를 생각한다. 출력 $u$의 변화율을 입력이 정하고 시작값은 0이다.[1,3]

$$
\frac{du}{dy}=a(y),\qquad u(0)=0.
$$

이 문제의 정확한 연산자는 antiderivative이다.[1,3]

$$
\mathcal G[a](y)=\int_0^y a(s)\,ds.
$$

적분 변수 $s$는 출력 좌표 $y$와 구별되는 내부 변수이다. 한 점의 출력은 그 점까지의 입력 구간에 의존한다. 따라서 branch가 입력 표본 전체를 처리한다는 것은 단순히 출력 위치와 같은 곳의 입력값 하나를 전달한다는 뜻이 아니다.[1,3]

예를 들어 $a(s)=\alpha+\beta s$로 제한하면 적분을 직접 계산하여 다음을 얻는다. $\alpha,\beta$는 입력을 정하는 실수 계수이며, 아래는 학습 결과가 아니라 정확한 계산 예이다.[1,3]

$$
\mathcal G[a](y)=\alpha y+\frac{\beta}{2}y^2.
$$

이 경우 입력에 따라 바뀌는 계수와 모든 입력에 공통인 좌표 함수 $y,y^2$가 분리된다. DeepONet은 이런 분리 표현을 network로 학습한다. 일반 연산자에서는 이 예처럼 적은 항으로 정확하게 표현된다는 보장이 없으므로, 항의 수와 근사 오차를 함께 검토해야 한다.[1,2]

## 2. Branch–trunk 표현

기본 DeepONet은 입력의 유한 표본에서 계수 벡터를 만들고, 그 계수를 좌표 함수와 결합한다. $m$은 입력 sensor 수, $p$는 결합에 사용하는 잠재 벡터의 길이이다. Sensor 위치 $x_1,\ldots,x_m$은 모형 전체에서 고정한다.[1,2]

### (1) 입력 부호화와 출력 복원

입력 함수를 벡터로 만드는 encoder를 $\mathcal E$라 하자.[1,2]

$$
\mathcal E[a]=\boldsymbol a
=(a(x_1),\ldots,a(x_m))^{\mathsf T}\in\mathbb R^m.
$$

Branch network $\boldsymbol b_\theta$는 이 벡터를 $p$개 계수로 바꾼다. Trunk network $\boldsymbol t_\theta$는 $d$차원 출력 좌표를 같은 길이의 벡터로 바꾼다.[1,2]

$$
\boldsymbol b_\theta:\mathbb R^m\to\mathbb R^p,
\qquad
\boldsymbol t_\theta:\Omega\subset\mathbb R^d\to\mathbb R^p.
$$

스칼라 bias $c_\theta$를 허용하면 모형의 정확한 정의는 다음과 같다. 정답에 대한 등식이 아니라 **모형 내부 계산에 대한 등식**이다.[1,2]

$$
u_\theta[a](y)
=c_\theta+\boldsymbol b_\theta(\mathcal E[a])^{\mathsf T}
\boldsymbol t_\theta(y)
=c_\theta+\sum_{k=1}^p b_{\theta,k}(\mathcal E[a])t_{\theta,k}(y).
$$

여기서는 하나의 branch가 $p$개 성분을 함께 내놓는 unstacked 구조를 기준으로 한다. 계수마다 별도 branch를 두는 stacked 구조도 원 논문에 제시되어 있지만, 마지막 결합의 의미는 같다. 분석 문헌에서 좌표 의존적인 기준 함수 $t_0(y)$를 더하는 일반화도 사용한다. 위 식은 그 기준 함수를 상수로 제한한 형태이다.[1,2]

구조 그림은 [원 논문 Fig. 1](https://arxiv.org/html/1910.03193v3#S1.F1)에서 확인할 수 있다. 아래 표는 그림에서 두 입력이 갈라지고 다시 합쳐지는 이유를 정리한다.[1,2]

| 구성 요소 | 받는 정보 | 만드는 정보 |
| --- | --- | --- |
| Encoder | 입력 함수 $a$와 고정 sensor | 순서가 정해진 표본 벡터 |
| Branch | 표본 벡터 $\boldsymbol a$ | 입력에 따라 달라지는 계수 $b_k$ |
| Trunk | 출력 좌표 $y$ | 좌표 함수의 값 $t_k(y)$ |
| 내적과 bias | 두 잠재 벡터 | 해당 입력과 좌표의 예측값 |

입력을 바꾸고 좌표를 고정하면 branch 계수가 바뀐다. 입력을 고정하고 여러 좌표를 읽으면 같은 branch 계수에 서로 다른 trunk 값을 결합한다. 이 때문에 하나의 입력장을 여러 위치에서 평가할 때 branch 계산을 재사용할 수 있다. 이는 구조에서 따르는 계산 방식이며, 특정 구현의 속도 향상 수치를 뜻하지 않는다.[1,2]

### (2) 공유 함수 공간과 비선형성

학습을 마친 뒤 $\theta$를 고정하면 모든 예측장은 같은 affine 공간에 속한다. $\operatorname{span}$은 주어진 함수들의 모든 선형결합을 뜻한다.[1,2]

$$
\mathcal V_\theta
=c_\theta+\operatorname{span}\{t_{\theta,1},\ldots,t_{\theta,p}\}.
$$

Trunk 함수들이 선형 독립이라는 조건은 기본 구조에 없으므로 이 공간의 차원은 최대 $p$이다. 이들은 학습된 좌표 함수이지, 자동으로 직교하거나 정규화된 물리적 고유 mode가 되는 것은 아니다. 출력 복원이 선형결합이라는 사실은 입력에서 출력까지의 연산자가 선형이라는 뜻도 아니다. Branch가 비선형이면 계수의 입력 의존성도 비선형일 수 있다.[1,2]

이 구분은 선형 연산자의 조건과 대조하면 명확하다. 임의의 허용 입력 $a_1,a_2$와 실수 $\lambda$에 대해 선형성을 가지려면 다음을 만족해야 하지만 기본 DeepONet은 이를 강제하지 않는다.[1,2]

$$
\mathcal G[\lambda a_1+a_2]
=\lambda\mathcal G[a_1]+\mathcal G[a_2].
$$

유한 차원 복원의 제한은 여러 함수의 예측을 한 행렬에 모아도 드러난다. $N$개 입력과 공통된 $Q$개 출력점에서 $B_{ik}=b_k(\mathcal E[a_i])$, $T_{jk}=t_k(y_j)$라 정의하면 예측 행렬 $U_\theta\in\mathbb R^{N\times Q}$는 다음과 같다.[1,2]

$$
U_\theta-c_\theta\boldsymbol 1_N\boldsymbol 1_Q^{\mathsf T}
=BT^{\mathsf T},
\qquad \operatorname{rank}(BT^{\mathsf T})\le p.
$$

$\boldsymbol 1_n$은 모든 성분이 1인 길이 $n$ 벡터이다. 이 rank 상한은 앞의 결합식에서 직접 얻은 대수적 결과이다. 좌표점을 늘리면 같은 함수 공간을 더 촘촘히 읽을 수 있지만 공간 자체의 차원은 늘지 않는다. $p$를 늘리는 실험과 $Q$를 늘리는 실험이 다른 이유이다.[1,2]

## 3. Sensor 표본화와 정보 손실

입력 sensor는 단순한 데이터 저장 형식이 아니라 모형이 구별할 수 있는 입력의 범위를 결정한다. Sensor 수가 유한하면 서로 다른 두 함수가 같은 표본 벡터를 가질 수 있다. 기본 DeepONet은 표본 벡터 이후의 정보만 사용하므로, 이 차이를 branch의 깊이만으로 복구할 수 없다.[1,2]

### (1) Sensor 위치와 입력 규약

Sensor가 반드시 균일 격자일 필요는 없다. 그러나 기본 구조에서는 모든 입력에 대해 위치, 개수, 배열의 순서가 동일해야 한다. 위치 자체가 branch에 함께 들어가는 구조가 아니므로, 배열의 첫 성분이 나타내는 위치를 추론 시점에 바꾸면 모형이 학습한 입력의 의미도 바뀐다.[1,2]

새로운 측정 위치의 값을 기존 sensor로 보간하여 입력할 수는 있지만, 이때는 보간으로 생긴 오차도 입력 오차에 포함된다. 출력 좌표 $y$를 자유롭게 바꾸는 능력을 입력 sensor 집합을 자유롭게 바꾸는 능력으로 해석하면 안 된다. 이 문서의 고정 encoder는 임의의 sensor 개수나 위치를 자동으로 처리하는 구조를 포함하지 않는다.[1,2]

| 바꾸는 대상 | 기본 모형에서의 의미 | 별도로 확인할 사항 |
| --- | --- | --- |
| 같은 입력의 출력 좌표 | Trunk를 새 좌표에서 평가 | 새 위치의 예측 정확도 |
| 입력 함수 | 같은 sensor에서 새 값을 입력 | 함수 분포에 대한 일반화 |
| Sensor 위치·개수 | Encoder의 정의 변경 | 재표본화 또는 구조 변경 |
| Sensor의 배열 순서 | Branch 성분의 의미 변경 | 학습 당시 순서와 일치 여부 |

입력 함수를 연속 함수로 제한한 것은 점값 $a(x_i)$를 명확하게 정의하기 위해서이다. 더 일반적인 함수 공간이나 평균값을 측정하는 장비를 다룰 때는 encoder의 정의부터 바꾸어야 한다. 단순히 함수 공간의 이름만 바꾸고 같은 점값 식을 적용하는 것은 충분하지 않다.[1,2]

### (2) 구별 불가능한 입력의 오차

두 입력 $a_1,a_2$가 모든 sensor에서 같으면, 고정된 $\theta$에 대해 다음이 정확히 성립한다.[1,2]

$$
\mathcal E[a_1]=\mathcal E[a_2]
\quad\Longrightarrow\quad
\mathcal G_\theta[a_1]=\mathcal G_\theta[a_2]=v.
$$

반면 정답 출력 $u_1=\mathcal G[a_1]$, $u_2=\mathcal G[a_2]$는 다를 수 있다. 출력 공간의 norm을 $\|\cdot\|$로 쓰면 삼각부등식으로 다음을 얻는다.[1,2]

$$
\max\{\|u_1-v\|,\|u_2-v\|\}
\ge\frac12\|u_1-u_2\|.
$$

이는 위 encoder 구조에서 직접 유도한 하한이다. 두 오차의 합이 정답 사이 거리보다 작을 수 없으므로 적어도 하나는 거리의 절반 이상이다. 출력이 다른 두 입력을 encoder가 합쳐 버렸다면 어떤 branch를 학습하더라도 두 정답을 동시에 정확히 맞출 수 없다. 다만 입력 차이가 정답에 영향을 주지 않아 $u_1=u_2$라면 이 하한은 0이다. 모든 입력 정보 손실이 같은 크기의 출력 오차를 만드는 것은 아니다.[1,2]

예를 들어 sensor 사이에서만 값이 변하는 입력 차이를 생각할 수 있다. 앞의 적분 문제에서는 그 차이의 누적 적분이 출력에 나타나는지가 중요하다. 따라서 입력 sensor의 수를 늘릴 필요가 있는지는 입력 함수가 얼마나 빠르게 변하는지만으로 결정할 수 없다. 그 변화가 목표 연산자를 거쳐 출력 함수에 얼마나 큰 차이를 만드는지도 함께 고려해야 한다. 원 논문의 sensor 분석과 독립 분석의 encoding error는 이 두 측면을 구분하는 근거를 제공한다.[1,2]

## 4. 데이터 구성과 학습

지도 학습에서는 서로 다른 입력 함수와 각 함수의 정답 출력값을 모은다. 학습에 사용할 입력 함수를 몇 개 선택했는지와 각 함수의 출력장에서 몇 개 좌표를 표본화했는지는 구분해야 한다. 정답 쌍의 총 행 수만 기록하면 독립적인 입력 함수의 수가 드러나지 않아 데이터 규모를 잘못 해석할 수 있다.[1,2,3]

### (1) 함수 표본과 좌표 표본

입력 $a_i$의 $j$번째 출력 좌표를 $y_{ij}$, 정답값을 $u_{ij}=\mathcal G[a_i](y_{ij})$라 하자. 학습 자료 한 행의 구조는 다음과 같다.[1,3]

$$
\bigl(\mathcal E[a_i],\ y_{ij},\ u_{ij}\bigr).
$$

$N$개 입력마다 $Q$개 좌표를 사용하면 행은 $NQ$개이지만 서로 다른 입력 함수는 $N$개이다. 같은 입력 함수에서 가져온 여러 좌표별 학습 행에는 동일한 branch 입력 벡터가 반복해서 들어간다. 함수마다 출력 좌표가 달라도 기본 결합식을 평가할 수 있으며, 완전한 공통 출력 격자를 반드시 요구하지 않는다.[1,3]

출력 좌표가 공통이면 앞 절의 $BT^{\mathsf T}$ 계산을 사용할 수 있다. 서로 다르면 각 $(i,j)$에 맞는 trunk 값을 결합해야 한다. 두 경우의 자료 의미는 같지만, 공통 좌표라고 가정한 행렬곱에 함수마다 다른 좌표 배열을 넣으면 다른 물리 위치를 같은 열로 취급하게 된다. 이는 출력 좌표와 정답값의 대응을 유지해야 한다는 구조적 요구이다.[1,3]

### (2) 목적 함수와 가중치

입력 분포를 확률측도 $\mu$로 나타내고, 출력 영역의 측도를 $\nu$로 나타내자. 여기서는 $\nu(\Omega)=1$로 정규화하여 영역 평균을 사용한다. 제곱 적분이 유한하다는 조건에서 목표 risk를 다음처럼 정의한다.[2,3]

$$
\mathcal R(\theta)
=\mathbb E_{a\sim\mu}\left[
\int_\Omega|\mathcal G_\theta[a](y)-\mathcal G[a](y)|^2\,d\nu(y)
\right].
$$

출력장이 유차원 물리량이면 이 risk의 단위는 그 물리량 단위의 제곱이다. 적분을 부피로 나누지 않는 규약은 영역 크기를 추가로 포함한다. 같은 문제의 학습과 평가에서는 어느 규약을 썼는지 일치시킨다. 다성분 문제로 확장할 때는 서로 단위가 다른 오차를 그대로 더하기 전에 각 성분의 척도를 정해야 한다. 이는 제곱오차 정의의 차원에서 따르는 요구이다.[2,3]

함수 $i$마다 $Q_i$개 좌표를 사용할 때, 양의 가중치 $w_{ij}$를 $\sum_jw_{ij}=1$로 두면 empirical loss는 다음과 같다.[2,3]

$$
\widehat{\mathcal R}(\theta)
=\frac1N\sum_{i=1}^N\sum_{j=1}^{Q_i}
 w_{ij}|\mathcal G_\theta[a_i](y_{ij})-u_{ij}|^2.
$$

균일하게 표본화한 같은 수의 좌표에는 $w_{ij}=1/Q_i$를 쓸 수 있다. 비균일 격자로 영역 평균을 근사하려면 그 적분에 맞는 가중치를 사용한다. 함수마다 출력 좌표 수 $Q_i$가 다르면 모든 학습 행에 동일한 가중치를 주는 방식과, 먼저 함수별 오차의 평균을 구하는 방식은 서로 다른 목적 함수를 만든다. 이 문서에서 채택한 함수별 평균 방식에서는 출력 좌표를 많이 표본화한 함수가 학습에 자동으로 더 큰 가중치를 갖지 않는다.[2,3]

학습은 branch와 trunk의 매개변수를 함께 조정하여 이 유한 표본 loss를 낮춘다. 입력 분포와 좌표 분포를 충분히 대표하는지, 수치해로 만든 정답의 오차가 얼마인지, 최적화가 어느 수준까지 진행됐는지는 loss 정의만으로 결정되지 않는다. 따라서 모형 구조와 함께 데이터 생성 조건 및 학습·검증 분리 기준을 기록해야 한다.[1,2]

## 5. 근사 가능성과 실제 오차

Universal approximation은 원하는 연산자에 가까운 모형이 **존재한다**는 진술이다. 그러나 이미 정해진 sensor 수와 잠재 차원, 유한한 학습 데이터를 사용하는 모형이 실제 최적화 과정에서 그 근사해를 찾아낸다는 뜻은 아니다. 이 차이를 지우면 구조의 표현 가능성을 시험 정확도의 보장으로 잘못 해석하게 된다.[1,2]

### (1) 근사 목표와 오차의 범위

근사 정확도를 논할 때에는 어떤 입력 집합과 norm을 사용했는지 먼저 정한다. 허용 입력 집합을 $K\subset\mathcal A$라 하고 그 위의 균일 오차를 다음처럼 정의하자. 아래 식은 달성 가능성을 보장하는 정리가 아니라, 모든 허용 입력과 출력 좌표에서 요구하는 오차의 기준이다.[1,2]

$$
E_\infty(\theta;K)
=\sup_{a\in K}\sup_{y\in\Omega}
|\mathcal G[a](y)-\mathcal G_\theta[a](y)|.
$$

앞 절의 risk $\mathcal R$는 입력 분포와 출력 측도에 따른 평균제곱오차이다. 두 측도가 확률측도이고 $\mu(K)=1$이면, 오차의 제곱을 그 상한으로 제한한 뒤 적분하여 다음을 얻는다. $E_\infty$가 유한하다는 조건에서 성립하는 직접적인 계산이다.[1,2]

$$
\mathcal R(\theta)^{1/2}\le E_\infty(\theta;K).
$$

역방향의 결론은 평균 오차의 정의만으로 얻을 수 없다. 드문 입력이나 작은 출력 영역에서 큰 오차가 나도 평균에서는 그 비중이 작을 수 있기 때문이다. 균일 오차를 요구하는 문제와 분포 평균을 최소화하는 학습 문제를 구별해야 한다. 입력 집합 $K$를 넓히는 것과 같은 집합에서 평가 좌표를 늘리는 것도 서로 다른 변화이다.[1,2]

실제 학습에서는 sensor 수와 배치, branch와 trunk의 구조, 활성화 함수, 잠재 차원 $p$를 정한 뒤 매개변수를 찾는다. 이 선택이 정의하는 모형 집합을 $\Theta$라 하면 $\inf_{\theta\in\Theta}\mathcal R(\theta)$는 그 집합에서 가능한 최선의 risk이고, 학습으로 얻은 특정 매개변수의 risk와는 구별된다. 이 최솟값이 0인지, 유한 데이터로 그것에 얼마나 가까이 갈 수 있는지는 별도의 근사·최적화·일반화 문제이다.[1,2]

이 문서는 임의의 연산자에 대한 균일 근사 정리를 적용하여 특정 $m$이나 $p$를 정하지 않는다. 이미 고정된 encoder가 서로 다른 정답을 가진 입력들을 구별하지 못한다면 3절의 하한이 남는다. 따라서 존재 정리의 일반적 의미와 별개로, 실제 선택한 모형의 입력 정보와 출력 표현력을 검증해야 한다.[1,2]

### (2) 오차 원인의 분리

다음 표는 구조적 근사 오차와 학습 과정의 오차를 구분하는 진단 틀이다. 각각의 항이 항상 독립적이거나 단순히 더해진다는 등식을 주장하는 표가 아니다.[1,2]

| 오차의 원인 | 부족한 정보 또는 표현 | 확인할 비교 |
| --- | --- | --- |
| 입력 부호화 | 유한 sensor가 놓친 입력 변화 | Sensor 배치·개수를 바꾼 학습 |
| 출력 복원 | 공통 trunk 공간의 표현력 | 잠재 차원 $p$를 바꾼 학습 |
| 유한 network 근사 | 입력 표본에서 계수로 가는 변환 | Branch의 크기와 구조 비교 |
| 최적화 | 주어진 모형에서 낮출 수 있었던 loss | 초기화와 학습 이력 비교 |
| 일반화·표본화 | 유한 자료와 목표 분포의 차이 | 보지 않은 함수와 좌표의 시험 |

입력 복원 함수를 $\mathcal D$라 하고 $\widetilde a=\mathcal D(\mathcal E[a])$로 쓰면, encoder가 남긴 정보로 복원한 입력과 원래 입력을 비교할 수 있다. 출력 공간에서 삼각부등식을 적용하면 다음과 같은 진단용 상한을 얻는다.[1,2]

$$
\|\mathcal G[a]-\mathcal G_\theta[a]\|
\le
\|\mathcal G[a]-\mathcal G[\widetilde a]\|
+\|\mathcal G[\widetilde a]-\mathcal G_\theta[a]\|.
$$

이 식은 $\widetilde a$가 연산자의 정의역에 있을 때 성립한다. 첫 항은 입력을 유한 정보로 바꾼 영향이고 둘째 항은 그 복원 입력의 출력을 모형이 얼마나 잘 나타내는지이다. $\mathcal D$는 분석을 위한 선택이며 기본 DeepONet 내부에 실제로 구현해야 하는 network가 아니다. 이를 도입하면 sensor 부족과 branch 학습 실패를 같은 원인으로 취급하는 것을 피할 수 있다.[1,2]

추가로 연산자가 선택한 입력·출력 norm에서 Lipschitz 연속이고 상수가 $L_\mathcal G$이면 첫 항은 다음처럼 제한된다.[1,2]

$$
\|\mathcal G[a]-\mathcal G[\widetilde a]\|
\le L_\mathcal G\|a-\widetilde a\|.
$$

이 식은 연산자의 안정성 가정을 명시한 조건부 상한이다. 입력 표본 오차가 작아도 큰 $L_\mathcal G$를 가진 문제에서는 출력 오차가 민감할 수 있다. 반대로 실제 연산자가 특정 입력 변화를 약하게 전달한다면 거친 표본으로도 그 출력에는 충분할 수 있다. 어느 경우인지는 문제별 분석이나 sensor 비교 실험이 필요하다.[1,2]

## 6. Physics-informed DeepONet

Physics-informed DeepONet은 branch–trunk 표현을 유지하면서 지배 방정식과 초기·경계 조건의 잔차를 학습 목표에 넣는다. 여기서 partial differential equation (PDE)의 잔차란 예측장을 방정식에 대입했을 때 남는 불일치이다. 하나의 고정 입력에 대한 해를 찾는 경우와 달리, operator 학습에서는 여러 입력 함수에 대해 이 제약을 적용한다.[3,4]

### (1) 좌표 미분과 잔차

지배 미분 연산자를 $\mathcal F$, 경계·초기 조건 연산자를 $\mathcal B$, 주어진 조건값을 $g[a]$라 쓰면 목표 해의 조건은 다음과 같다. 시간 문제에서 $y$는 시간과 공간 좌표를 함께 포함할 수 있다.[3,4]

$$
\mathcal F[a,u](y)=0,\qquad
\mathcal B[u]=g[a].
$$

고정 입력 $a$에 대한 좌표 미분에서는 branch 계수가 상수이다. Trunk가 해당 차수까지 미분 가능하면 $y_\ell$에 대한 도함수는 다음과 같다. $\ell$은 좌표 성분을 나타낸다.[3,4]

$$
\partial_{y_\ell}u_\theta[a](y)
=\sum_{k=1}^p b_{\theta,k}(\mathcal E[a])
\partial_{y_\ell}t_{\theta,k}(y).
$$

Automatic differentiation은 이 모형의 계산 그래프를 미분한다. 그것이 정확한 물리 해의 미분을 알려 주는 것은 아니므로, 미분값의 정확도도 학습과 평가의 대상이다. 강한 형태의 PDE 잔차를 계산하려면 필요한 미분 차수에 맞는 매끄러움을 확보해야 한다. 이 문서는 불연속 해의 약한 형태나 shock 처리를 이 식만으로 해결한다고 주장하지 않는다.[3,4]

함수값 오차와 미분 오차의 차이는 간단한 계산으로 확인할 수 있다. 무차원 $y\in[0,1]$와 양의 정수 $n$에 대해 오차 함수 $e_n$을 다음처럼 정하자.[3,4]

$$
e_n(y)=\frac{\sin(2\pi n y)}{n},\qquad
 e_n'(y)=2\pi\cos(2\pi n y).
$$

이 예에서는 함수값의 최대 오차가 $1/n$으로 감소하지만, 같은 함수의 도함수에 대한 최대 오차는 $2\pi$로 유지된다. 이는 두 문헌에서 구별하는 해 근사와 잔차 근사의 차이를 보여 주는 대수적 예이며, 실제 학습의 오차 형태라고 가정한 것은 아니다. 출력값의 평균제곱오차만 작다는 이유로 미분 방정식까지 잘 만족한다고 판단할 수 없다.[3,4]

### (2) 복합 loss와 조건 부과

정답 자료의 loss를 $\mathcal L_{\mathrm{data}}$, 내부 잔차 loss를 $\mathcal L_{\mathrm{res}}$, 초기·경계 조건 loss를 $\mathcal L_{\mathrm{cond}}$라 하자. 비음수 가중치 $\lambda$를 사용한 전형적인 목표는 다음과 같이 정리할 수 있다.[3,4]

$$
\mathcal L
=\lambda_{\mathrm{data}}\mathcal L_{\mathrm{data}}
+\lambda_{\mathrm{res}}\mathcal L_{\mathrm{res}}
+\lambda_{\mathrm{cond}}\mathcal L_{\mathrm{cond}}.
$$

서로 다른 항의 단위와 크기가 다를 수 있으므로 무차원화나 명시적인 기준 척도 없이 가중치의 숫자만 비교해서는 안 된다. $\lambda_{\mathrm{data}}=0$이면 내부 해의 정답값 없이 학습하는 설정도 가능하다. 그러나 입력 함수, 방정식, 초기·경계 조건과 잔차를 평가할 점들은 여전히 필요하다. 특히 경계 조건을 빼고 내부 방정식만 맞추는 것은 원래 문제의 해를 지정하는 것과 다르다.[3,4]

앞의 적분 예에서 입력 $a_i$마다 $Q$개의 잔차 평가점 $z_{ij}$를 쓰면 구체적인 loss를 다음처럼 만들 수 있다. 여기서는 모두 무차원이며 입력의 점값 $a_i(z_{ij})$를 알 수 있다고 가정한다.[3,4]

$$
\mathcal L_{\mathrm{res}}
=\frac1{NQ}\sum_{i=1}^N\sum_{j=1}^Q
\left|\partial_yu_\theta[a_i](z_{ij})-a_i(z_{ij})\right|^2.
$$

시작값 0을 부과하는 항은 다음과 같다.[3,4]

$$
\mathcal L_{\mathrm{cond}}
=\frac1N\sum_{i=1}^N|u_\theta[a_i](0)|^2.
$$

Branch의 sensor와 잔차 평가점은 서로 다른 역할을 한다. Sensor에서는 모형에 넣을 입력을 읽고, 잔차 평가점에서는 방정식의 불일치를 계산한다. 입력이 sensor의 측정값으로만 주어졌다면 임의의 $z_{ij}$에서 $a_i(z_{ij})$를 정확히 알고 있다고 가정할 수 없다. Sensor 자체에서 잔차를 평가하거나 입력 재구성의 오차를 별도로 다루어야 한다. 이는 위 residual 식의 입력 요구에서 따르는 제한이다.[3,4]

적분 예에서는 출력 형태를 바꾸어 시작값을 정확히 만족시킬 수도 있다. 별도 DeepONet 출력 $v_\theta[a](y)$에 대해 다음은 이 문서에서 선택한 간단한 구성이다.[3,4]

$$
u_\theta^{\mathrm{hard}}[a](y)=y\,v_\theta[a](y).
$$

유한한 $v_\theta[a](0)$에 대해 시작값은 정확히 0이다. 그러나 미분 잔차에는 $\partial_y(yv)=v+y\partial_yv$가 들어가므로, 단순히 기존 residual 식의 출력 이름만 바꾸어서는 안 된다. 이 구성은 해당 시작값을 만족시키는 방법일 뿐, 모든 경계 조건에 그대로 적용하는 공식이나 학습 성공 보장이 아니다.[3,4]

### (3) 무차원 좌표와 물리적 잔차

좌표를 정규화한 모형을 물리 방정식에 넣을 때는 미분의 척도를 복원한다. 물리 좌표 $Y=L y$, 물리 출력 $u_{\mathrm{phys}}=U_*u_\theta$로 두고 $L,U_*>0$를 각각 길이와 출력의 기준 척도로 선택하면 chain rule에 의해 다음을 얻는다.[3,4]

$$
\frac{\partial u_{\mathrm{phys}}}{\partial Y}
=\frac{U_*}{L}\frac{\partial u_\theta}{\partial y},
\qquad
\frac{\partial^2 u_{\mathrm{phys}}}{\partial Y^2}
=\frac{U_*}{L^2}\frac{\partial^2 u_\theta}{\partial y^2}.
$$

이는 좌표 미분 정의에서 직접 얻은 관계이다. 시간에도 별도 척도를 사용하면 시간 미분에 해당 척도의 역수가 들어간다. Network가 정규화된 좌표에서 정확히 미분되더라도 이 계수를 빠뜨리면 다른 방정식의 잔차를 최소화하게 된다. 물리량의 단위, 좌표 정규화, loss의 기준 척도를 함께 기록해야 하는 이유이다.[3,4]

## 7. 일반화 평가와 적용 한계

DeepONet의 검증은 입력 함수, 출력 좌표, 잔차 평가점을 구분해야 한다. 아래 절차는 앞의 구조와 오차 분석에 근거한 권장 평가 방법이며, 이 문서에서 학습 실험을 수행한 결과가 아니다. 모형을 비교할 때에는 정확도뿐 아니라 어떤 분포와 표본화 조건에서 측정했는지를 함께 보고한다.[1,2,3,4]

### (1) 시험 집합과 정량 지표

학습에 쓰지 않은 입력 함수를 시험 집합으로 먼저 분리한다. 그다음 각 시험 함수의 출력값을 동일한 평가 좌표와 정규화 규칙으로 비교한다. 학습에 사용했던 입력 함수의 새로운 출력 좌표에서 시험한 결과와, 학습하지 않은 입력 함수로 시험한 결과는 별도로 표시한다. 입력의 변동 척도나 크기 범위를 바꾸는 분포 이동 시험도 출력점을 촘촘히 하는 시험과 분리한다.[1,2]

!!! info "[Measurement]"
    시험 함수 $a_i$의 정답 $u_{ij}$와 예측 $u_{\theta,ij}$를 동일한 출력 좌표에서 평가한다. $w_j>0$, $\sum_jw_j=1$인 영역 평균 가중치를 사용하면 절대 root mean square (RMS) 오차는 다음과 같다.[2,3]

    $$
    E_i^{\mathrm{abs}}=
    \left(\sum_jw_j|u_{\theta,ij}-u_{ij}|^2\right)^{1/2}.
    $$

    정답 norm이 0이 아닐 때 상대 $L^2$ 오차는 다음과 같이 정의한다.[2,3]

    $$
    E_i^{\mathrm{rel}}=
    \frac{E_i^{\mathrm{abs}}}{\left(\sum_jw_j|u_{ij}|^2\right)^{1/2}}.
    $$

절대 오차는 출력과 같은 단위를 갖고 상대 오차는 무차원이다. 정답이 0이거나 매우 작으면 상대값이 정의되지 않거나 작은 절대 오차를 과장할 수 있으므로 절대 오차와 함께 해석한다. 함수별 상대 오차의 평균과 모든 함수의 분자·분모를 합쳐 계산한 비율도 다른 통계량이다. 작은 크기의 출력과 큰 크기의 출력에 주는 비중이 달라지므로 집계 방식을 명시한다.[2,3]

예를 들어 $M$개 시험 함수의 평균 상대 오차는 다음처럼 정의한다. 이는 각 함수에 같은 비중을 주는 이 문서의 보고 규약이다.[2,3]

$$
\overline E^{\mathrm{rel}}=\frac1M\sum_{i=1}^M E_i^{\mathrm{rel}}.
$$

평균만 보고하면 일부 입력의 실패를 놓칠 수 있으므로 함수별 분포와 큰 오차 사례도 함께 확인한다. 이 권고는 risk가 분포 평균이라는 정의에서 따른다. 경계 주변처럼 관심 있는 부분 영역을 별도로 평가할 때에는 영역의 물리적 위치와 폭을 먼저 정하고, 격자를 바꾸어도 같은 영역을 비교한다.[2,3]

### (2) 원인별 비교 실험

$N$, $m$, $p$, $Q$를 한꺼번에 늘리면 성능이 좋아진 이유를 구분하기 어렵다. 다음 표의 비교는 각 양이 구조와 loss에서 맡은 역할을 분리한다.[1,2]

| 비교 대상 | 바꾸는 양 | 고정·기록할 조건 |
| --- | --- | --- |
| 입력 표본화 | Sensor 수 $m$와 배치 | 입력 분포, 출력 평가점, 재학습 조건 |
| 출력 표현력 | 잠재 차원 $p$ | Sensor와 함수 데이터, 매개변수 수 |
| 함수 일반화 | 서로 다른 입력 수 $N$ | 함수당 좌표 수, 동일한 시험 함수 |
| 좌표 표본화 | 함수당 학습점 수 $Q$ | 입력 함수 집합, 독립 평가 좌표 |
| 출력 해상도 | 추론 좌표의 밀도 | 동일한 모형, 동일한 입력 sensor |

기존 sensor 수에 맞춰 학습한 branch에 길이가 다른 입력 배열을 그대로 넣는 것은 sensor 개수의 영향을 비교하는 올바른 ablation이 아니다. 각 encoder에 맞는 모형을 학습하여 비교한다. 반면 출력 해상도 시험에서는 학습된 모형을 고정하고 trunk의 평가 좌표만 바꾼다. 이 두 절차를 섞으면 재학습 효과와 좌표 평가 능력을 구별할 수 없다.[1,2]

잠재 차원을 늘려도 오차가 줄지 않는다면 입력 정보나 데이터 수, 최적화가 제한 요인일 수 있다. 다만 특정 원인을 loss 곡선 하나만으로 확정하지는 않는다. 독립적인 sensor 비교와 데이터 수 비교가 같은 결론을 지지하는지 확인하는 방식이 필요하다. 이는 여러 오차 원인이 함께 작용한다는 분석에서 도출한 진단 절차이다.[1,2]

### (3) 물리 제약과 설명 가능성의 한계

Physics-informed 모형은 학습에 쓰지 않은 좌표에서도 residual과 초기·경계 조건을 검사한다. 유한 collocation 점의 loss가 작다는 사실은 연속 영역 전체의 residual이 작다는 사실과 다르다. 이 문서의 적분 예에서는 residual과 해 오차의 관계를 직접 구할 수 있다. 연속 입력 $a$에 대해 정답 $u$는 $u'=a$, $u(0)=0$을 만족한다고 하자. 연속 미분 가능한 예측 $u_\theta$의 residual을 $r_\theta(y)=u_\theta'(y)-a(y)$, 초기 오차를 $\delta_0=u_\theta(0)$로 정의하면 다음은 두 식을 빼고 적분한 정확한 관계이다.[1,3]

$$
u_\theta(y)-u(y)=\delta_0+\int_0^y r_\theta(s)\,ds.
$$

$r_\theta$가 제곱 적분 가능할 때 $0\le y\le1$에서 Cauchy–Schwarz 부등식을 적용하면 다음 상한을 얻는다. 여기서 $\|r_\theta\|_{L^2(0,1)}$는 연속 구간 전체에서 계산한 norm이다.[1,3]

$$
\sup_{0\le y\le1}|u_\theta(y)-u(y)|
\le |\delta_0|+\|r_\theta\|_{L^2(0,1)}.
$$

따라서 이 예에서는 초기 오차와 연속 residual을 함께 줄이면 해 오차를 제한할 수 있다. Residual이 정확히 0이어도 초기 오차가 남으면 예측은 정답에서 상수만큼 어긋날 수 있다. 이 계산을 임의의 PDE에 대한 상한으로 확대하지 않으며, 유한 평가점의 residual loss를 위 연속 norm과 동일시하지 않는다.[1,3,4]

Trunk가 출력하는 개별 성분을 특정 물리 mode에 직접 대응시키려는 해석에도 주의가 필요하다. 가역 행렬 $A\in\mathbb R^{p\times p}$로 계수와 좌표 함수를 동시에 바꾸면 동일한 내적을 얻는다. $A^{-\mathsf T}$는 역행렬의 전치이다.[1,2]

$$
(A\boldsymbol b)^{\mathsf T}(A^{-\mathsf T}\boldsymbol t)
=\boldsymbol b^{\mathsf T}\boldsymbol t.
$$

이는 학습된 분해의 해석이 출력 예측만으로 유일하게 정해지지 않는다는 대수적 근거이다. 특정 trunk가 물리적으로 의미 있다는 주장은 별도의 정규화, 구조 제약, 물리량과의 대조를 필요로 한다. 예측이 정확한 것과 내부 성분에 고유한 물리적 의미가 있는 것은 따로 평가한다.[1,2]

마지막으로 입력 분포나 경계 조건, 영역을 바꾸는 문제는 단순히 같은 모형의 출력 좌표 수를 늘리는 문제가 아니다. 새로운 조건이 입력 표현과 학습 자료에 어떻게 들어가는지 먼저 정의해야 한다. 기본 DeepONet의 함수 표현과 근사 정리는 유용한 출발점이지만, 배치할 문제의 sensor 규약·정답 범위·물리 조건을 생략하는 근거가 될 수는 없다.[1,2,3,4]

## 8. 요약

- DeepONet은 입력 함수의 sensor 값으로 branch 계수를 만들고, 출력 좌표에서 얻은 trunk 함수값과 결합한다.
- 입력 sensor의 정보량, 공통 출력 함수 공간의 차원, 학습 함수 수와 좌표 수는 서로 다른 제한을 만든다.
- Universal approximation은 가정 아래의 존재 명제이며 고정 모형의 최적화 성공이나 새로운 분포의 정확도를 보장하지 않는다.
- Physics-informed 학습은 여러 입력에 대해 미분 잔차와 초기·경계 조건을 부과한다. 함수값 오차와 미분 오차는 별도로 검사한다.
- 새로운 입력 함수, 새로운 출력 좌표, 입력 분포 이동을 구분하여 검증하고 단위·정규화·오차 집계 방식을 명시한다.
