# Model reduction

모형 축소의 공통 원리에서 저랭크 근사와 투영 방법을 거쳐 Wannier 기저와 mode-space의 구성·검증으로 이어지는 문서를 안내한다.

Wannier 문서의 전자구조 배경은 [Electronic structure](../../computational-materials-science/electronic-structure/index.md), mode-space 문서의 수송 배경은 [Quantum transport](../../computational-materials-science/quantum-transport/index.md)에서 찾아볼 수 있다.
