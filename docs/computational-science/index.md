# Computational science

Computational science 영역에서는 machine learning, AI agent와 수치해석처럼 여러 과학·공학 분야에 재사용할 수 있는 계산 방법과 알고리즘을 다룬다. Python 기반 알고리즘과 자료구조, 그래프 기반 재료 표현과 3차원 대칭성을 반영하는 신경망, computer vision의 CNN 구조, large language model을 도구 및 명시적 workflow와 결합하는 AI agent의 계산 구조를 제공한다.
