## 1. Content Authoring Workflow

원하는 주제와 깊이, 특별히 다루거나 제외할 범위를 요청하면 인터넷 조사부터 시작한다. 비자명한 주장은 직접 확인한 독립 출처 두 개 이상과 모델의 과학 지식이 같은 범위에서 일치할 때만 본문에 채택한다. 용어, 기호, 단위, 부호와 좌표계는 문서 전체에서 하나의 규약을 따른다.

구체적인 채택 기준과 조사 절차는 [연구 문서 작성 원칙](research-workflow.md)에 정리한다. 실제 작업에서 효과가 확인된 재사용 방법도 같은 문서에 누적한다.
