# High-Quality Writing Examples

이 디렉터리는 프로젝트 소유자가 잘 쓴 글로 선택한 예시를 보관한다.

새 과학 문서나 대폭 수정한 문서를 완성할 때에는 같은 분야 또는 설명 방식이 가장 가까운 `high/` 예시를 읽고 다음 세 측면에서 비교한다.

- **양적 수준:** 주제 범위에 필요한 설명의 폭과 깊이, 절, 수식, 그림, 표와 참고문헌이 예시에 비해 충분한가.
- **질적 수준:** 정의, 물리적 원인, 지배 관계, 측정·해석, 한계와 근거가 예시처럼 충실하고 명확한가.
- **형식 수준:** 문서 구조, 한국어 기술 문체, 용어와 기호, 인용, 그림·표·수식 형식이 예시 수준으로 정돈되었는가.

주제마다 필요한 분량과 구성 요소가 다르므로 글자 수, 절 수, 수식 수, 그림 수나 참고문헌 수를 기계적으로 같게 만들지 않는다. 전체 범위에 비추어 세 측면 중 부족한 부분이 보이면 글을 보완한 뒤 다시 비교한다.

완료 보고에는 비교한 예시와 양적·질적·형식적으로 비슷한 수준에 도달했는지를 짧게 적는다.

이 예시는 작성 품질을 비교하기 위한 자료이다. 예시의 주장과 인용을 새 문서의 과학적 근거로 대신 사용하지 않으며, 새 문서의 출처는 별도로 검증한다.
